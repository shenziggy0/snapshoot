1. 用当前已安装的旧版确认截图、滚动长截图和录屏可用，然后从菜单栏完全退出。
2. 按 README 中的 macOS 打包命令构建新版 DMG（Apple 芯片用 aarch64，Intel 用 x64）。打开 DMG，确认应用、Applications 链接及安装说明都可见。
3. 覆盖安装并打开新版。若系统拦截，按 DMG 内的说明处理。确认出现重新授权提示，若重置失败，确认提示列出失败项。
4. 选择稍后处理。从菜单栏打开“权限检查与修复”，检查屏幕录制和辅助功能。对未授权项可逐项重置并跳转到系统设置；重新授权后完全退出并重开。
5. 验证截图、滚动长截图和录屏。再次重启同一构建，确认权限保留且没有重置提示。
6. 保持版本号不变，重新构建含实际代码变化的 DMG 并覆盖安装。确认签名指纹不同，首次启动重新提示授权。
